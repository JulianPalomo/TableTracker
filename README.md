Este proyecto es un sistema de planificación de recursos empresariales (ERP) diseñado para el sector gastronómico. Permite la gestión eficiente de pedidos, productos, generación de comandas y facturación de consumos. Fue desarrollado como proyecto final de la asignatura Laboratorio 3, utilizando el lenguaje de programación Java.

Características principales:

Gestión de pedidos: Crear, leer, actualizar y eliminar pedidos.
Gestion de productos: Crear, leer, actualizar y eliminar productos.
Generación de comandas: Organización de órdenes para la cocina.
Facturación: Cálculo y emisión de facturas para los clientes.
Interfaz amigable: Diseñado con Java Swing para una experiencia de usuario intuitiva.

Tecnologías utilizadas:

Lenguaje: Java
Interfaz gráfica: Java Swing
Gestión de dependencias: Maven/Gradle (si aplicaste alguna)
IDE: IntelliJ IDEA

This project is an Enterprise Resource Planning (ERP) system tailored for the gastronomic sector. It enables efficient management of orders, products, command generation for the kitchen, and billing. Developed as a final project for the Laboratory 3 course, using Java programming language.

Main Features:

Order Management: Create, read, update, and delete orders.
Products Management: Create, read, update, and delete products.
Command Generation: Organize orders for the kitchen.
Billing: Calculate and issue invoices for customers.
User-friendly Interface: Designed with Java Swing for an intuitive user experience.


Technologies Used:

Language: Java
Graphical Interface: Java Swing
Dependency Management: Maven/Gradle (if applicable)
IDE: IntelliJ IDEA
